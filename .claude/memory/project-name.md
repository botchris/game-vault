The project is public (source-available, see [[license]]); the maintainer decided to keep the name **Game Vault**
(2026-10-08), after considering alternatives (GameShelf, Ludoteca, GameCellar, Ludoshelf…).

- Known overlap: Phalcode's GameVault (github.com/Phalcode/gamevault-app, ~800★), a self-hosted
  platform for DRM-free games. Different product (it serves game files; this one catalogs what
  you own).
- **How to apply:** don't suggest renaming again. When writing public-facing text (README, repo
  description), state clearly what this project is (a catalog of the games you own across stores,
  keys and discs) so it is not mistaken for Phalcode's.
