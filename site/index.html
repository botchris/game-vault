    Count yours tonight.

    Run the command on your server, open the port in a browser, create your user and connect your first store.

    Run Game Vault

    docker run -d --name game-vault -p 8080:8080 -v game-vault-data:/config botchrishub/game-vault

    Then open http://your-server:8080. Images for amd64 and arm64.
